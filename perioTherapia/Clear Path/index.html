Good to know

MP4 has no transparency. It's flattened onto the background colour. For alpha on the web (Framer, WordPress) use WebM; for editors use the PNG sequence.

Transparent WebM needs Chrome or Edge to make, and won't open in QuickTime, Safari or most editors. For After Effects, Premiere, DaVinci or Final Cut, export the PNG sequence and convert it with the ffmpeg command shown there.

The animation loops seamlessly, so exporting whole loops gives a clip you can repeat. Video export uses WebCodecs: host this page over HTTPS (or localhost) rather than double-clicking the file.
