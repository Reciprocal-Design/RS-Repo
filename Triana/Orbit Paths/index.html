Reciprocal Space

Hero Orbit

A real 3D perspective view from inside a cluster of tilted rings, with dots making full orbits around them — a seamlessly loopable hero-section animation.

View

Perspective is the immersive view from inside the ring cluster — each dot is hidden for the half of its orbit that falls behind you. Flat steps back to a straight-on view of four concentric circles, so every ring and every dot's full orbit stays visible the whole time. Merge is three orbits that drift together into a tight cluster at dead center, then drift back apart to their own orbits — looping seamlessly.

Layout

Orbit size sets how big the outermost circle is. Ring spacing sets the gap between each concentric circle. Line width taper tapers thickness across the rings — negative thins them going outward, positive thickens them going outward, 0 keeps them all the same width.

Merge

How many orbit rotations one full drift-together-and-apart cycle takes. Tied to Orbit speed, so it always lands back on its starting spread exactly once per cycle — that's what keeps it loopable. Center cluster size sets how tightly the three dots huddle at dead center when fully merged — 0 collapses them to a single point.

Export

Records the live animation with Chrome/Edge's own built-in MediaRecorder — no external encoder. One "loop" is exactly one period of the orbit motion, so the exported clip always ends back where it started and plays seamlessly on repeat. Needs Chrome or Edge.
Downloads a small, dependency-free HTML file with the current view, colors, and motion settings baked in — no editor UI, no video weight. The canvas fills its container responsively at a 1600:600 aspect ratio, so a developer can drop it straight into a page. Hand this to them instead of an .mp4.
Each dot makes a full 360° orbit of its own ring on a shared timing — it's simply not drawn while behind the camera's near clip plane — so the whole scene returns to its exact starting state once per orbit period — that's what makes it loop cleanly both on screen and in the exported MP4.
