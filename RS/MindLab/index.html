Good to know

MP4 has no transparency — it's flattened onto the matte colour. For alpha on the web (Framer, WordPress) use WebM; for editors use the PNG sequence.

Transparent WebM needs Chrome or Edge to make, and won't open in QuickTime, Safari or most editors. For After Effects, Premiere, DaVinci or Final Cut export the PNG sequence and convert it with the ffmpeg command shown there.

Video export uses WebCodecs, so host this file over HTTPS (or localhost) rather than double-clicking it. Frame rate is constant and every frame is rendered exactly, not screen-recorded.

Very long or 4K PNG sequences use a lot of memory; in Chrome you'll be asked for a folder to write frames into directly.
