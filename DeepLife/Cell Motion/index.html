DeepLife

Cell Motion

Bring a still image to life with subtle, organic motion. Paint where things move, then tune how they move. Every animation is a seamless loop.

Image

Or drop an image onto the canvas. Re-uploading an image of the same size keeps your masks.

Mask layers

Each layer moves in its own way. White in a mask means full motion, black means none.

Select by tone

Build the mask from the image's brightness. Dark tones pick out stained nuclei; light tones pick out cytoplasm. Sliders update the last selection live.

Import / export mask

Paint masks in Photoshop if you prefer: a greyscale PNG at any size, white where things should move.

Motion

Pulse swells and settles like breathing. Swirl flows sideways like cytoplasm. Size is in image pixels: set it near a cell's width to move whole cells, smaller to wobble their edges.

All layers

Darkens tissue as it bunches up and lightens it as it stretches, as stain would.

Export

A single loop plays back seamlessly when set to repeat. Frames are rendered one by one, so the export is smooth whatever your machine's speed.

Project

A project file holds the image, all masks and every setting.
